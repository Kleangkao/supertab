# Judge demo on Android

Install `submission/supertab-clockin.apk`. Application id `app.supertab.shop`, version 1.0.0. SHA-256 `72d7c78915c89668a2041e0412493a674d2b22086e04670e4cb5b4f395c6c1ca`.

The phone needs a network connection. The app loads https://supertab-main.vercel.app/. It asks only for internet access.

1. Open SuperTab.
2. Choose “a black polo under $50,” then Find it.
3. Refine with “Navy is fine too.” The budget and polo stay in the request.
4. Open a result. Read the catalog price. Shipping and tax should say they are not confirmed.
5. Connect wallet. The picker should show Mobile Wallet Adapter. Connecting does not send a payment. If the Seeker wallet cannot load, use Explore without connecting and a public address instead.
6. Open Devnet checkout. Use View verified test order. The recorded order is refunded. Do not start a new test checkout.

Source: https://github.com/Kleangkao/supertab is private until access is granted. The pitch is `submission/pitch.html`. A public demo video of this installed app still has to be recorded and uploaded.
